## Objective

Analyze suspicious URLs and determine whether they are phishing or malicious by examining:

- URL reputation
- Domain reputation
- IP reputation
- Redirect behavior
- Threat intelligence indicators

## Tools Used

- VirusTotal
- URLScan.io
- AbuseIPDB

## Analysis Methodology

1. Extract URL from source.
2. Submit URL to VirusTotal.
3. Analyze URL behavior using URLScan.
4. Review domain reputation.
5. Review IP reputation.
6. Correlate findings.
7. Document verdict.
